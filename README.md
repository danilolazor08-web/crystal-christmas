# Crystal Christmas

Готовий статичний сайт (HTML/CSS/JS) для GitHub Pages / Netlify. Instagram: https://www.instagram.com/crystalchristmas.ua/

## ОБОВ'ЯЗКОВО перед публікацією

1. У `firebase.js` замініть `REPLACE_...` на конфігурацію **вашого наявного Firebase-проєкту**. Без цього товари, замовлення, адмінка і завантаження фото НЕ працюватимуть.
2. У Firebase увімкніть Authentication → Email/Password і створіть обліковий запис адміністратора.
3. Увімкніть Cloud Firestore і Cloud Storage, налаштуйте **правила безпеки**. Адміністратор має право записувати товари та фото, покупці — читати товари й створювати замовлення. Не відкривайте всім користувачам запис до `products`.
4. У Firebase Authentication → Settings → Authorized domains додайте ваш домен `crystalchristmas.netlify.app`.
5. У Netlify, що підключений до GitHub, завантажте файли в корінь репозиторію. Публікація має відбутися автоматично.

## Важлива сумісність

Це **нова реалізація сайту**, а не відредагована копія поточного репозиторію: його вихідний код не вдалося отримати. Вона використовує колекції Firestore `products` і `orders`, але структура наявної бази може відрізнятися. Перед заміною зробіть резервну копію репозиторію й перевірте сумісність. Зображення зберігаються у Firebase Storage, а URL — в масиві `images` товару. Поле `image` також підтримується для старих товарів.

Файли: `index.html`, `admin.html`, `style.css`, `script.js`, `admin.js`, `data.js`, `firebase.js`.
