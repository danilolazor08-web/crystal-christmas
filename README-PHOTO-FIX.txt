CRYSTAL CHRISTMAS — ВИПРАВЛЕННЯ ФОТО

1. Розпакуйте ZIP і завантажте всі файли в корінь GitHub-репозиторію із заміною.
2. Дочекайтеся оновлення Netlify, відкрийте адмінку, оновіть сторінку Ctrl+Shift+R.
3. Для збереження товару потрібен авторизований користувач Firebase з UID, вказаним у правилах Firestore.
4. Фото стискаються автоматично до приблизно 85 КБ кожне. При перевищенні ліміту буде повідомлення.

УВАГА: живий запис у Firebase не перевірений; правила Firestore не змінювалися.
