CRYSTAL CHRISTMAS — ВХІД ЗА ПОСИЛАННЯМ (БЕЗ ПАРОЛЯ)

ВАЖЛИВО: секретне посилання саме по собі не захищає базу. Тому ми використовуємо анонімну сесію Firebase, яка автоматично запам’ятовується в одному браузері.

ОДНОРАЗОВЕ НАЛАШТУВАННЯ:
1. Firebase Console → Authentication → Sign-in method → Anonymous → Enable → Save.
2. Завантаж файли цього ZIP на GitHub, дочекайся Netlify.
3. Відкрий /admin.html у своєму звичайному браузері (не інкогніто). На екрані побачиш UID цього браузера.
4. Скопіюй UID і заміни PASTE_YOUR_ANONYMOUS_UID_HERE у ДВОХ файлах: admin.js і FIRESTORE-RULES.txt.
5. Скопіюй вміст FIRESTORE-RULES.txt у Firebase Console → Firestore Database → Rules → Publish.
6. Завантаж оновлений admin.js на GitHub.
7. Онови /admin.html: адмінка відкриється без входу, з правом зберігати товари.

НЕ видаляй дані сайту/куки для домену, не заходь в інкогніто: анонімний UID може загубитися. Якщо це станеться, доведеться повторити прив’язку. На іншому пристрої потрібна окрема прив’язка.

НЕ став allow write: if true у Firestore Rules. Це дозволить будь-кому змінювати товари.
